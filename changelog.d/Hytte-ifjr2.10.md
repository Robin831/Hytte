category: Removed
- **Goal Race settings replaced by the Stride race calendar** - The Goal Race block in Settings → Training (race name, date, distance, target time) is gone, along with the `goal_race_name`, `goal_race_date`, `goal_race_distance` and `goal_race_target_time` preferences behind it. Stride's race calendar is the only place races are recorded now, and the macro plan's own goal is what training is aimed at, so the AI profile block, the workout-insights prompt and the race-prediction prompt no longer carry a second, contradicting goal race. Rows already written for the removed keys are left in place but ignored everywhere; the API rejects new writes to them. (Hytte-ifjr2.10)

category: Added
- **Stride switches in Settings** - Enable Stride, training days per week (1–7) and the weekly distance cap (1–500 km) are now editable under Settings → Training. They previously had to be written into the database by hand, because the preferences API refused any key outside its allow-list. Out-of-range days or caps and a non-boolean enable value are rejected with a clear error rather than silently stored. (Hytte-ifjr2.10)

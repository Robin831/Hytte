- **Macro plan HTTP endpoints** - `GET /api/stride/macro/current` and `GET /api/stride/macro/{id}` return a macro training block with its week rows, the goal currently in force and the full goal history; `POST /api/stride/macro/generate` regenerates the block from the upcoming Monday and `POST /api/stride/macro/extend` appends a block to the end of the horizon on demand. Both POST endpoints take the same per-user lock as the Monday run, answer 409 while a generation is already in flight, and never touch weeks already materialised into a 7-day plan. (Hytte-oe73o)

category: Fixed
- **Kiosk no longer shows demo data when it cannot fetch** - A kiosk with a token now keeps the demo fixture off screen entirely: before its first successful poll it shows a full-screen status panel ("Connecting…", "Cannot reach the server", or "Kiosk token rejected") instead of fabricated departures and sensor readings. A token that is revoked or expires after the kiosk has been running now switches the screen to the "rescan the QR code" panel instead of freezing on the last payload behind a small stale badge, and rescanning a QR code starts from a blank screen rather than briefly re-displaying the revoked token's departures, forecast and indoor readings. The kiosk also sends its token as an `Authorization: Bearer` header rather than a query parameter, so it no longer lands in reverse-proxy access logs, and the demo fixture's departure times were corrected so the token-less demo actually renders departures.

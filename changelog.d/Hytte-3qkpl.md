- **Stride weekly run keeps the long-term plan alive** - The Monday run now refreshes the race prediction, tops up the 26-week macro horizon (a fresh block when there is none, an extension block when fewer than 8 weeks remain), generates the coming week's plan and sends the confirmation push. A failed block generation no longer costs you the week: the weekly plan is still generated and a push tells you to open Stride and retry. (Hytte-3qkpl)
- **Plan generation is serialised per athlete** - The weekly cron and the manual Regenerate button now take the same per-user lock, so two runs can never overlap and spend two Claude calls on the same week. (Hytte-3qkpl)

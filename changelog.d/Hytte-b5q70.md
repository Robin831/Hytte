- **Live punch estimate keeps running past midnight** - A punch-in that is still open after midnight (for example 22:00 still running at 01:00) now shows a growing running total instead of the "start time is in the future" warning. The day view keeps the punch session's date so a wrapped shift can be told apart from a genuinely future start time, and only adds the extra day when the clock has actually wrapped, so the estimate matches what punching out records. A punch-in left open for more than a day is treated as forgotten rather than counted through the nights in between, and the day view says so — with a locale-formatted date — instead of claiming the start time is in the future. The estimate is only shown on the day the punch-in belongs to, so another day's sessions can't be mixed into the total. (Hytte-b5q70)

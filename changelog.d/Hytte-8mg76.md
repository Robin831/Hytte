category: Added
- **Download my data** - Settings now offers a self-service data export above the delete-account action. It streams a JSON archive of your profile, notes, workouts, lactate tests and stages, preferences and session metadata. Encrypted fields are decrypted before download, session tokens are never included, and secret preference values (Claude CLI path, Wordfeud credentials) are exported with the value blanked out. (Hytte-8mg76)
- **Sign-in device details** - New sessions record the browser user agent and client IP, encrypted at rest, so the data export can show where each session was started. Sessions created before this change export those fields as empty. (Hytte-8mg76)

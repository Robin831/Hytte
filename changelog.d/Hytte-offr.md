category: Added
- **Grocery Offers** - New feature (flag `offers`, default off) that mirrors the weekly grocery offers behind mattilbud.no (Tjek API) into SQLite and ranks them per user. A daily 06:30 Europe/Oslo sync (plus a stale-aware warm-run at startup) sweeps all 16 Norwegian chains (~1,400 offers) with polite pacing and per-dealer failure isolation; offers carry price, before-price (→ discount %), derived unit price (kr/l, kr/kg, kr/stk), catalog image and validity window. Each user keeps a watchlist of priority keywords ("melk", "vaskemiddel") matched compound-aware (melk → HELMELK, not melkesjokolade); matches rank above everything else, then best discount first. The page has chain filter chips, text search, an admin manual-refresh button and one-tap add-to-grocery-list. (Hytte-offr)

category: Fixed
- **Norwegian comma decimals no longer silently dropped on the salary page** - Chrome and Edge report an empty value for a `type="number"` input containing a comma, so typing "7,5" into standard hours or "1250,50" into an amount saved a wrong figure (0, or the 7.5 default) with no warning. Every field in the salary config editor, the monthly override form and the trekktabell editor is now a decimal text input parsed with `parseDecimal`, so both "," and "." work, partially typed values like "0," survive typing, and an unparseable or missing value shows an inline error and blocks the save instead of writing a fallback.

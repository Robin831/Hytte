- **Stride macro prompt text and input assembly** - New `internal/stride/macro_prompt.go` holding the instruction block for the 26-week macro training plan and the Go code that assembles the athlete-specific inputs for it. The instructions reuse the existing `bakkenPhilosophy` constant and add a periodisation doctrine (4-week mesocycles of 3 build weeks plus a deload at 60-70%, a base -> build -> peak -> taper arc, a two-week taper before an A-race, B/C races run as quality sessions, at most +10% volume week-over-week and one hard session per 1-2 weeks), the standing half-marathon priority rule verbatim, and the JSON output contract for `{goal, mesocycles, weeks}`. The inputs pass the athlete's profile, race predictions, race calendar through the horizon, race results and constraints through verbatim, and summarise the rest to keep the prompt small: 26 weeks of training history as one table row each (volume merged with planned-vs-completed sessions and easy/threshold/hard minutes), the acute:chronic ratio and training status, six monthly VO2max points, the last three lactate tests, and the workout library as names and types only. Extension blocks additionally carry the previous block's goal, periodisation and last eight week specs so training continues instead of restarting. Treadmill calibration, raw workouts, the legacy `goal_race_*` preferences and stride notes are deliberately left out. The generation mode reuses the stored `generated_by` vocabulary (`scheduled`/`extension`/`manual`) rather than introducing a second set of names, and a start week that is not a Monday or a mode outside that vocabulary is now a hard error instead of a silently empty history table. The plan-history column is labelled Planned/Evaluated and renders `?` where a week's plan was never evaluated, so a week the athlete trained is no longer reported to the coach as zero sessions completed. The weekly prompt now shares the macro prompt's race time and pace formatting, so both quote the same race the same way. Prompt text and input assembly only — nothing calls it yet. (Hytte-r9od8)

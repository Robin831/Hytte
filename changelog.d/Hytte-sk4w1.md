- **Night dimming and pixel-shift for kiosk screens** - Kiosk displays now dim between sunset and sunrise and nudge their layout by a few pixels every few minutes to protect always-on panels from burn-in. Each kiosk token can override dimming from Settings, both when it is created and later from the token list: keep the sun-driven default, turn dimming on or off, and optionally set a fixed `HH:MM` dim window that replaces the sunset/sunrise times. Changes made in the token list are saved through a new `PUT /api/kiosk/tokens/{id}/dim` endpoint that leaves the rest of the token's config untouched. (Hytte-sk4w1)

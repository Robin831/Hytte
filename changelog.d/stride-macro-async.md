- **Regenerate / Extend long-term plan no longer fails after two minutes** - `POST /api/stride/macro/generate` and `/extend` now start the block generation in the background and answer 202 at once; the outcome arrives on the training SSE stream as `stride_macro_ready` (the page re-reads the block) or `stride_macro_failed` (the page shows the reason). The synchronous request used to be dropped by the Cloudflare edge after ~100s of silence, which cancelled the request context and SIGKILLed the Claude CLI mid-generation ("Could not regenerate the long-term plan", 2026-09-07). The button stays busy with a hint that the run takes minutes, and a block finished while the page was closed is picked up on the next visit.
